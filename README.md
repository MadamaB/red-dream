# THE RED DREAM

*A journey through the unreal.*

An immersive 3D dream in the browser (Three.js, WebGL, Web Audio): a crimson descent, chains melting into a lake, a white swan, a hall of liquid glass, a passage of rising doors, a garden of mirrors that show other dreams — and the dream begins again.

The experience carries itself: no scrolling needed. All geometry, materials and sound are generated in the browser.

**Experience it** through GitHub Pages. Sound on, headphones recommended.
